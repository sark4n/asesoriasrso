# Medición comercial de RSO

Vercel Web Analytics mide visitas y páginas consultadas cuando se habilita en el proyecto. El componente elimina consultas y fragmentos de las URL antes de registrar visitas. No registra nombres, empresas, mensajes ni el contenido preparado para WhatsApp. No se agregan eventos personalizados: Vercel los limita a planes Pro/Enterprise.

## Seguimiento de consultas

Registrar cada consulta comercial recibida en una planilla interna con fecha, fuente declarada, servicio, estado (conversación, oportunidad calificada, propuesta, ganado o perdido) y valor cuando corresponda. Preguntar cómo conoció RSO si no está claro. No publicar esa planilla ni incorporarla al repositorio.

Comparar por mes las visitas, conversaciones recibidas desde la web, oportunidades calificadas, propuestas y negocios ganados. Un clic en WhatsApp no demuestra que el mensaje se envió. Las conversaciones y ventas requieren seguimiento comercial; Web Analytics no puede observarlas.

La primera semana sirve para comprobar recepción de datos. Para evaluar cambios, usar periodos comparables y considerar la procedencia del tráfico y la cantidad de visitas; no atribuir variaciones pequeñas automáticamente al diseño.

## Pendientes y límites

- Confirmar recepción de visitas en el panel después del despliegue.
- Los clics en WhatsApp no están instrumentados en el plan Hobby. Una futura herramienta de eventos requiere decidir proveedor y configuración.
- Presentación personal: pendiente de decisión del propietario; no se publica nombre, cargo ni fotografía por inferencia.
